Workaround: temporarily `pm enable --user 0 com.google.android.apps.tv.launcherx`, change the setting, then `pm disable-user --user 0 com.google.android.apps.tv.launcherx` and `cmd package set-home-activity --user 0 com.gathin.tvhome/.MainActivity`.

Left: setupwraith or one of the 12 phase-1 packages. Netflix itself last updated 2026-10-30. Both test changes were reverted at 20:13 (DNS on, launcherx disabled, Home = launcher).
